# Environment Variables Configuration

This project requires a `.env` file to securely store API keys for the various AI and database services used by NyayaSakhi-SWATI. 

## Required API Keys

The following tokens are used throughout the model processing, RAG (Retrieval-Augmented Generation) pipeline, and backend services:

### 1. Groq (`GROQ_API_KEY`)
- **Purpose**: Powers the primary Large Language Model (LLM) inference.
- **Usage**: Used for fast generation of legal summaries, extraction of facts from user narratives, and predicting legal remedies under the PWDVA.
- **Get it here**: [Groq Cloud Console](https://console.groq.com/keys)

### 2. Google Gemini (`GEMINI_API_KEY`)
- **Purpose**: Used as a fallback LLM and for specialized natural language understanding tasks.
- **Usage**: Assists in complex reasoning tasks or acts as a secondary model for the LAMP² framework when required.
- **Get it here**: [Google AI Studio](https://aistudio.google.com/app/apikey)

### 3. Pinecone (`PINECONE_API_KEY` & `PINECONE_INDEX_NAME`)
- **Purpose**: Vector database for the RAG architecture.
- **Usage**: Stores and retrieves embeddings of Indian laws (IPC, CrPC, PWDVA, etc.) and prior legal precedents to ground the AI's responses in factual, statute-aligned data.
- **Get it here**: [Pinecone Console](https://app.pinecone.io/)

### 4. Jina AI (`JINA_API_KEY`)
- **Purpose**: Embeddings generation.
- **Usage**: Converts text (both user queries and legal documents) into high-quality vector embeddings before they are stored in or queried against the Pinecone database.
- **Get it here**: [Jina AI Platform](https://jina.ai/)

### 5. OpenRouter (`OPENROUTER_API_KEY`) *(Optional)*
- **Purpose**: LLM Routing/Aggregator.
- **Usage**: Used for accessing various alternative LLMs if the primary providers (Groq/Gemini) are unavailable or for specific specialized prompts.
- **Get it here**: [OpenRouter](https://openrouter.ai/keys)

---

## Setting up your `.env` file

1. Create a file named `.env` in the root directory (alongside `main.py`).
2. Copy the template below and replace the placeholder values with your actual API keys.

```env
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
PINECONE_API_KEY=your_pinecone_api_key_here
PINECONE_INDEX_NAME=nyayasakhi-index
JINA_API_KEY=your_jina_api_key_here
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

**⚠️ Security Warning**: Never commit your `.env` file to version control (GitHub/GitLab). Ensure `.env` is listed in your `.gitignore` file.
